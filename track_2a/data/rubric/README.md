# Rubric and feedback rules

| File | Content |
|---|---|
| `criteria.json` | The FHGR assessment grid: 11 criteria × 4 levels (Ungenügend / Ausbaufähig / Gut / Sehr gut). Each level has a description (de, en) and an example (de); labels are in de, en, fr and it. `core_challenge_criterion: true` marks the six criteria named in the challenge description (clarity, relevance, motivation, self-awareness, communication, concrete examples). |
| `feedback_guidelines.json` | The FHGR guidelines for age-appropriate feedback, split into 27 rules with ids (T1 … A1) in de and en. S4 (feedback language) is a marked addition. The ids are referenced by `annotations.guideline_refs` and `feedback_examples.poor_feedback_violations`. |

Human-readable version, including the FHGR reference feedback prompt: [../docs/feedback_guidelines.md](../docs/feedback_guidelines.md). Both files are generated by `scripts/build_rubric.py`; edit the script, not the JSON.
